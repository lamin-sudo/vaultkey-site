02 / what is actually in it

Every feature below is in the APK you are downloading.

01

Argon2id, then AES-256-GCM

Your master password derives the key with Argon2id; each record is sealed with AES-256-GCM and bound to its own id and title as authenticated data, so a stored row cannot be swapped for another.

02

Sealed in the Android Keystore

The data key never sits on disk in the clear. It is wrapped by a Keystore key, and optional biometric unlock puts a second, hardware-backed wrapper on it that only your fingerprint or face can open.

03

Autofill and passkeys

VaultKey registers as an Android autofill service and as a credential provider, so sign-in fills in apps and browsers and WebAuthn passkeys live in the same vault as your passwords.

04

Auto-lock you can set

Thirty seconds, five minutes, never — your choice. Backgrounding the app ends the session and zeroes the key; repeated wrong attempts lock the vault instead of letting anyone keep guessing.

05

TOTP codes and a real generator

Store 2FA authenticator codes beside the login they belong to, and generate passwords with length and character rules you control when you create one.

06

Health you can read

A scan of your own vault reports weak, reused and ageing passwords with a score, and a list you can tap straight through to fix each entry.

07

Encrypted backup, your files

Export the vault as one encrypted file through the system file picker, and restore it on another phone — including into a brand-new vault, which is how a fresh install gets your data back.

08

Three languages, both directions

English, Arabic and French, with the Arabic layout mirrored end to end. The language switch lives in Settings and takes effect immediately.

03 / optional sync

Sync goes to your own Drive, as ciphertext.

Cloud sync is off until you sign in with a Google account and enable it. When it is on, one hidden file in your Google Drive appData folder holds the vault — and the scope drive.appdata means neither the file browser nor any other app can see it.

1

A sync key, not your password

A random 256-bit key is generated for the vault. Your master password only wraps it.

2

Encrypt, then upload

Records are decrypted in memory, sealed with the sync key, and only the sealed container is sent.

3

One shared file, one lock

Devices write the same file. A recorded lock and If-None-Match stop one phone from silently crushing another's changes.

4

Silently renewed

The access token is refreshed through Google's authorization client — no client secret inside the APK, and no refresh token stored.

05 / read this before you trust it

What VaultKey does not do.

It is not a company and not a cloud service. There is no vault recovery if you lose your master password — the derivation is the only way in, and nothing we hold can undo it. It ships as a self-signed APK for personal use, not through Google Play, so updates are manual and the signing certificate is a debug key rather than a published release key. If any of that is a deal-breaker for how you plan to use it, this may not be the right tool for you — and it is better to say so here than in a support email.

06 / install

Four steps to a sealed vault.

1

Download the APK

The button above saves VaultKey-v52.apk directly — about 6 MB, no intermediate page.

2

Allow this file

Android asks once to confirm an app from an unknown source. It is a side-loaded app, so that prompt is expected.

3

Pick one master password you will keep

Long beats clever: it is the only thing between the encrypted rows and nothing. Write it down on paper, not in the vault.

4

Turn on what you want

Autofill, biometric unlock, auto-lock timing and Drive sync are all separate switches, all off until you set them.
